# Content Review Notes, Québec Mode v1

This pack is a starter content pack, not a finished cultural archive.

## Reviewed enough for private prototype

- Québec spoken compression examples
- Standard vs spoken warnings
- Basic Québec expressions
- Sacres and register labels
- Visual dictée / phonetic reformulation items

## Needs manual/user completion over time

- Exact external video URLs for meme/archive items
- Exact credits for every clip or image
- Final images/screenshots if used
- Sensitive-content filtering per friend/group
- Audio assets if added privately

## Sensitive material

Some Québec meme references involve vulgarity, intoxication, accidents, allegations, harassment, or people shown in embarrassing circumstances. For this reason, the app should support `content_warning`, `credit_display_text`, and `context_summary_fr`, and should let you exclude items easily.
