# Ceinture fléchée Badge System v1

Québec Mode uses a ceinture fléchée progression metaphor. Each completed track adds detail to the belt.

## Ranks

1. Ceinture nouée croche, entered Québec Mode
2. Premier fil, Québec parlé completed
3. Motif simple, expressions completed
4. Motif rouge dangereux, sacres completed
5. Ceinture de survivant, standard vs parlé completed
6. Ceinture d’archive, culture comique and archives started
7. Ceinture fléchée complète, all regular tracks completed
8. Ceinture fléchée légendaire, final exam perfect score

## UX rule

Rewards are visual-first. Sound is optional. Every reward must have visible text, a badge, and a replay-sound button only if audio exists.
