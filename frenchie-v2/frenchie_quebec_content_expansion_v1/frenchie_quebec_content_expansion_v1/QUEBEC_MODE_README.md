# Frenchie, Québec Mode Content Expansion v1

Ce pack ajoute le contenu de départ pour la section séparée **Prêt pour le français québécois?**.

But: enseigner le français québécois de Montréal et du Québec comme expérience culturelle séparée de l'app principale de français standard.

Règle centrale: **ce n'est pas le français d'examen**. Le contenu doit toujours distinguer:
- français standard
- français parlé québécois
- registre
- utilité réelle
- sécurité pour un examen
- contexte culturel

Les vidéos, extraits et références culturelles doivent rester sous forme de **liens externes**. Ne pas héberger de vidéo ou d'audio protégé par défaut.
